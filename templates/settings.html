iOS Shortcuts — bank SMS → transaction

  1. Generate a token above and copy it.
  2. On iPhone open Shortcuts → Automation → +.
  3. Choose Message. Optionally filter by sender (e.g. HDFC, SBIINB, AX-HDFCBK, VK-PhonePe).
  4. Add action Get Contents of URL:
    • URL: https://YOUR-DOMAIN/api/v1/sms-transaction
    • Method: POST
    • Headers: Authorization = Bearer YOUR_TOKEN, Content-Type = application/json
    • Body (JSON): 
      {
  "text": "Message Body",
  "sender": "Sender"
}
      Map Message Body / Sender from the automation input.
  5. Optional: first test with "dry_run": true in the JSON (parse only, no save).
  6. Turn off Ask Before Running if you want it automatic (iOS may still confirm for Message automations).

Name accounts with last 4 digits (e.g. HDFC 1234) so SMS A/c hints can match the right account.
