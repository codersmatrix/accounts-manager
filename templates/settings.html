To enable email reminders, set these in app.py (or as environment variables):

  • MAIL_USERNAME – your SMTP email (e.g. Gmail address)
  • MAIL_PASSWORD – app password (for Gmail: create one at myaccount.google.com/apppasswords)
  • MAIL_DEFAULT_SENDER – usually the same as MAIL_USERNAME
  • MAIL_SERVER – default smtp.gmail.com
  • MAIL_PORT – default 587

Example (near the top of app.py): 

app.config['MAIL_USERNAME'] = 'you@gmail.com'
app.config['MAIL_PASSWORD'] = 'your-16-char-app-password'
app.config['MAIL_DEFAULT_SENDER'] = 'you@gmail.com'
